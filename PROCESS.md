# Process

## AI Tools Used

I used ChatGPT to brainstorm possible arguments, organize the structure of my
essay, and improve the clarity of some sentences. I wrote the main ideas and
personal examples myself.

## What I Kept

ChatGPT suggested distinguishing between asking AI to generate code and being
able to judge whether the code supports my creative intention. I kept this idea
because it helped me express my main argument more clearly.

## What I Rejected

ChatGPT initially produced a general paragraph claiming that everyone should
learn programming because technology is the future. I rejected it because it
was vague and did not reflect my personal experience as a designer. I replaced
it with a specific example from my own creative practice.

## Final Responsibility

I reviewed and edited the final essay myself. I also verified the sources and
made sure that the submitted argument represents my own position.
